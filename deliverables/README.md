These are the existing rendered files copied from the Codex task without regenerating or changing them.

- [Download the full-resolution master](centrix-behind-the-class-final.mp4?raw=true): 3,546,785 bytes (3.38 MiB), 1080×1920, 30 fps, 27 seconds.

On GitHub, open a file and choose **Download raw file** to save it to your Mac. The files can be downloaded directly from this branch without merging the pull request.

Both videos use H.264 video and 48 kHz stereo AAC audio. The supplied narration and original logo are preserved. SHA-256 checksums are included in `SHA256SUMS.txt` and match the original Codex output files byte-for-byte.

To check a download on macOS:

```sh
shasum -a 256 centrix-behind-the-class-final.mp4
```
